Panels
======

3DSC is an end-to-end toolkit for georeferenced 3D survey workflows in Blender.
From import and QA to LOD, optimization, and export, it supports a complete
operational pipeline with contextual help per tool.

Panels are organized in the *3DSC* tab of the Blender sidebar and can be
rearranged from their top-right handle. Each page below documents one panel:
its parameters, buttons, and behaviors.

.. admonition:: Remember

   The add-on, within the preference menu of Blender, offers a feature that
   checks for new updates and then asks user for the installation.
